# Contributing to WordSwift

## Development Setup

```bash
git clone https://github.com/djinn/WordSwift
cd WordSwift
pip install -r requirements.txt
```

## Running Tests

```bash
PYTHONPATH=. python3 tests/test_api.py
```

## Code Style

- Python: PEP 8, type annotations everywhere
- C: C11 with clean headers

## Pull Requests

1. Fork the repo
2. Create a feature branch
3. Run tests
4. Submit PR
